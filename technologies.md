# Salon Management Project - Technology Stack

## Frontend Technologies

* **Framework:** Next.js (React Framework)
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **UI Components:** Radix UI
* **Form Management & Validation:** React Hook Form with Zod
* **Animations:** Framer Motion
* **Icons:** Lucide React
* **Notifications:** Sonner
* **Authentication State/Cookies:** jsonwebtoken and cookie

## Backend Technologies

* **Runtime:** Node.js
* **Framework:** Express.js
* **Language:** TypeScript
* **Database ORM:** Prisma
* **Authentication & Security:** JWT (jsonwebtoken) and bcryptjs (Password hashing)
* **Validation:** Zod
* **File Uploads & Media Storage:** multer (File handling) and Cloudinary (Cloud storage for images/media)
* **Utilities:** cors, dotenv, http-status
